# SemTalk Landing Page

This repository contains a SemTalk-inspired landing page built with:

- React
- TypeScript
- Fluent UI
- Azure Static Web Apps support

## Getting Started

Install dependencies:

```bash
npm install
```

Run the app locally:

```bash
npm start
```

Build for production:

```bash
npm run build
```

## Debug in VS Code

The repo includes a launch configuration in [.vscode/launch.json](./.vscode/launch.json).

1. Open the project in VS Code.
2. Press `F5`.
3. VS Code starts the React app and opens the browser debugger.

## Project Notes

- The app is intentionally class-based React.
- The content and visual direction are tailored toward SemTalk and its focus on process management, enterprise knowledge, and AI agents.
- Azure Static Web Apps routing is configured in [staticwebapp.config.json](./staticwebapp.config.json).
